# 图片作用分析

## 用途
逐张看竞品的主图和副图，写出每张图的类型和它向买家传达什么，结果回填到“图片分类总表”的“图片分析”列，也是第 5 步统计和方案的依据。

## 适用条件
第 4 步。每个子代理负责 **5 个 ASIN**，可以同时开多个子代理（读本地图片，不受亚马逊限流影响）。只分析主图和副图，A+ 图不分析。

## 规则

### 必须真的看图
- 先运行 `python -X utf8 <SKILL_DIR>/scripts/contact_sheet.py --work <work> --asins <这批 ASIN>`，它给每个商品生成拼图 `products/<ASIN>/sheet_1.jpg`（图多时还有 sheet_2.jpg），每格左上角标好了“主图 / 副图N”。
- 打开（Read / 看图工具）这个商品的**全部拼图**，按格子上的标签逐张分析；格子里的小字看不清时，再单独打开 `thumbs/` 里那一张。
- **每张图都要填 `text`**：照抄图上最大、最清楚的 2～6 个词，保持原文（英文、德文照抄，不翻译），例如 `"WHY CHOOSE US Heat-Resistant Mat"`。图上没有文字写 `""`。`check_excel.py` 会用文字识别核对这些词是否真的在图上，对不上就报“分析与图片不符”，只能重新看图重写。
- 只写图上看得到的东西：图上的文字（卖点文案、数字、认证标志）、画面元素（人物、场景、产品摆放、图标、对比表）。
- **禁止套模板**：不能用同一句话套所有商品，也不能只根据标题推测。`check_excel.py` 会检查同一句话是否出现在 3 个以上商品里。
- 图上的英文卖点要翻成中文概括，关键数字照抄（如 “500mg”“7 Forms”“3rd Party Tested”）。

### 类型（只能从下表选一个，方便脚本统计）
| 类型 | 判断要点 |
|---|---|
| 白底主图 | 纯白背景、只有产品（和包装） |
| 场景主图 | 第 1 张图但不是纯白背景 |
| 卖点总览 | 一张图列 3 个以上卖点图标/短句 |
| 功能利益点 | 集中讲 1～2 个功效或好处 |
| 使用场景 | 人物或环境中使用产品 |
| 使用方法 | 步骤、用量、怎么用 |
| 尺寸规格 | 尺寸标注、容量、数量、规格参数 |
| 成分材质 | 成分表、配方、原料、材质说明（保健品的 Supplement Facts 也算） |
| 结构细节 | 局部特写、内部结构、工艺 |
| 对比图 | 和其他产品/普通款对比 |
| 信任背书 | 认证、检测、奖项、专家/医生推荐、销量证明 |
| 适用人群 | 讲给谁用（性别、年龄、身份） |
| 包装清单 | 包装内含物、套装组成 |
| 品牌故事 | 品牌理念、工厂、团队 |
| 售后保障 | 商家的承诺：保修期、退换货、客服支持。讲产品本身好清洗、好维护、可拆洗、可进洗碗机的不算，归“功能利益点”（讲好处）或“使用方法”（讲怎么拆洗） |
| 其他 | 以上都不是（在说明里写清是什么） |

一张图同时有多种内容时，选**占画面面积最大**的那一种。

### 说明（message）的写法
- 一句话，30～70 个字，格式：**传达什么 + 靠什么画面传达**。
- 好：“强调 7 种镁形态全覆盖，用 7 个彩色胶囊图标环绕瓶身并逐一标注名称”
- 差：“配方拆解图”（只有类型，没有内容）
- 差：“产品很好，值得购买”（空话）

## 示例
`analysis/B08WPLW4VN.json`：
```json
{
  "asin": "B08WPLW4VN",
  "images": [
    {"position": "主图", "type": "白底主图", "text": "Magnesium Breakthrough",
     "message": "白底展示瓶身正面和散落的两粒胶囊，突出品牌名和“Magnesium Breakthrough”字样"},
    {"position": "副图1", "type": "成分材质", "text": "7 Forms of Magnesium",
     "message": "列出 7 种镁形态名称和每份含量，用分层圆环图表现“全谱镁”的配方结构"},
    {"position": "副图2", "type": "功能利益点", "text": "Fall asleep faster",
     "message": "主打睡眠和放松，用夜晚卧室背景配“Fall asleep faster”大字"}
  ]
}
```
回填到表格后显示为：
```
主图｜白底主图：白底展示瓶身正面……
副图1｜成分材质：列出 7 种镁形态名称……
```

## 子代理提示词模板
```
你负责分析亚马逊竞品的主图和副图。不要做其他事。

工作目录：<work>
你负责的 ASIN：B0..., B0..., B0..., B0..., B0...
规则：先完整读一遍 <SKILL_DIR>/references/image-analysis.md 并严格照做。

先运行：python -X utf8 <SKILL_DIR>/scripts/contact_sheet.py --work "<work>" --asins <逗号分隔的 ASIN>
对每个 ASIN：
1. 打开 <work>/products/<ASIN>/ 下全部 sheet_*.jpg 拼图（小字看不清再打开 thumbs/ 里的单张）。
2. 按拼图格子上的标签逐张写：position 照抄标签（主图 / 副图N）。
3. type 只能从类型表里选；text 照抄图上最大最清楚的 2～6 个原文词（没字写 ""）；message 写图上真实看到的内容。
4. 用 Write 写入 <work>/analysis/<ASIN>.json，格式见参考文件“示例”。
5. 没看过的图不能写。条数对不上时重新看拼图核对，不能删掉末尾几条凑数。

最后只回复 JSON：{"done": ["ASIN", ...], "skipped_images": [{"asin": "...", "index": 3, "reason": "..."}]}
```

## 特殊情况
- **图片是视频封面或纯文字海报**：照常分析，按内容选类型。
- **图片看不清**（太小、模糊）：打开 `images/` 里的原图再看。
- **图片里全是非中英文字**（德文、日文站点）：照样翻成中文概括。
- **商品抓取失败**（`status: failed`）：不写分析文件，表里会显示“【抓取失败】”。
- **重跑时**（第 6 步退回）：主代理会在提示词里写明哪些 ASIN、哪里不合格，只重写这些文件。

## 输出格式
每个 ASIN 一个 `<work>/analysis/<ASIN>.json`：`{"asin": "...", "images": [{"position", "type", "text", "message"}]}`。
`images` 的条数必须等于有图片文件的主图+副图张数，顺序一致。条数不对时重新看图核对，**禁止删掉末尾几条凑数**。
